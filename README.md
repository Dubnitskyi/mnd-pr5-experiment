# ПР5 МНД – статистичне опрацювання результатів експерименту

Навчальний пакет відтворення до практичної роботи 5 з дисципліни «Методологія наукових досліджень».

Набір даних згенерований (не реальний): час виконання однієї задачі програмування двома групами
по 40 учасників – без ШІ-асистента (`without_ai`) і з ШІ-асистентом (`with_ai`).

## Структура

| Файл | Зміст |
|---|---|
| `generate_data.py` | генерація набору даних (seed = 2026) |
| `data/task_time.csv` | сирі дані: `participant_id`, `group`, `experience_years`, `time_min` |
| `analysis.py` | очищення, описова статистика, графіки, перевірка припущень, тест, розмір ефекту, 95 % ДІ |
| `data/task_time_clean.csv` | дані після очищення |
| `results/results.json` | усі обчислені значення |
| `results/boxplot.png`, `results/histogram.png` | графіки |

## Правила аналізу (зафіксовані до аналізу)

- Рядки з пропущеним часом вилучаються.
- Значення менше 1 хв або більше 120 хв (ліміт часу на задачу) вважаються помилкою запису і вилучаються. Інші великі значення залишаються.
- Рівень значущості α = 0,05, тест двосторонній.
- Якщо в обох групах тест Шапіро–Уілка дає p > 0,05 – t-тест (Стьюдента, якщо тест Левена p > 0,05, інакше Велча) і d Коена.
  Інакше – U-тест Манна–Уітні, δ Кліффа і 95 % бутстреп-інтервал різниці медіан (10 000 вибірок, seed = 2026).

## Як запустити

Перевірено на Python 3.11.0.

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python generate_data.py
python analysis.py
```

Версії бібліотек: numpy 2.4.6, pandas 3.1.0, scipy 1.17.1, matplotlib 3.11.2 (див. `requirements.txt`).
